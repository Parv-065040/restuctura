# RESTRUCTRA

### AI-Based EMI Restructuring Advisor for MSMEs

> **ASK SIMPLE. ANALYSE DEEPLY. EXPLAIN SIMPLY.**

RESTRUCTRA is an AI-assisted financial restructuring prototype designed to help MSMEs understand their loan and cash-flow stress, simulate restructuring scenarios, and prepare for discussions with lenders.

---

## 🚀 Current Prototype

The current version combines:

- React + Vite frontend
- n8n workflow backend
- Deterministic financial analysis
- Document extraction
- Document reconciliation
- EMI restructuring scenarios
- AI-generated recommendations
- Bank-ready restructuring discussion plan
